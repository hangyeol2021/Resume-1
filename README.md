## 소개

헬스케어 AI와 의료데이터를 활용한 연구에 관심이 있습니다. 2021–2022학년도 학부연구생으로 활동했으며, AIM 논문 연구에 참여했습니다.

나고야시립대학교 교환학생 기간에는 일본 교수와 공동연구를 수행하고, 제100회 일본감염병학회 총회·학술강연회에서 구두발표했습니다. 연구 경험과 함께 개인 프로젝트를 통해 개발 경험도 쌓고 있습니다.
