# 김한결 | Kim Han-gyeol

한림대학교에서 공부하며, 일상의 아이디어를 직접 구현하는 개발 경험을 쌓고 있습니다. 자세 인식을 활용한 공부시간 측정 웹앱을 개발하고, AWS를 활용한 클라우드 서비스 구축을 학습하고 있습니다.

## 학력 및 주요 이력

| 시기 | 내용 |
| --- | --- |
| 2021학년도 | 한림대학교 입학 |
| 2023년 9월 | 대한민국 공군 입대 |
| 2025년 6월 | 대한민국 공군 전역 |
| 2025년 9월 | 나고야시립대학교 교환학생 시작 |

## 프로젝트

### 공시 — 자세 인식 기반 공부시간 측정

웹캠으로 공부 자세를 인식하고, 그 결과에 따라 공부시간을 측정하는 웹 애플리케이션입니다.

- Google Teachable Machine의 자세 인식 모델을 웹 타이머와 연결
- 공부 자세에 따른 자동 측정과 수동 측정 기능 구현
- AWS Lambda, API Gateway, DynamoDB를 활용한 기록 저장·조회 기능 개발 및 클라우드 리소스 배포

[프로젝트 저장소 보기](https://github.com/hangyeol2021/focus-sense)

## 관심 분야

- 인공지능을 활용한 웹 애플리케이션
- 사용자에게 도움이 되는 서비스 개발
- 클라우드 서비스 구축
