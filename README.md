## 소개

의료 AI를 전공하며 학부연구생으로 AIM 논문 연구에 참여했고, 나고야시립대학교 교환학생 기간에는 현지 교수와 공동연구를 수행해 제100회 일본감염병학회에서 구두발표했습니다.

최근 교내 LLM 가드레일 방어전에서 레드팀으로 참가해 은상을 받으며 생성형 AI 안전성 평가에 관심을 두게 되었습니다. 의료처럼 오류의 대가가 사람에게 돌아가는 분야일수록 AI의 안전성 검증이 먼저라고 생각합니다. 모델이 어디서 틀리는지 찾고, 기록하고, 근거 있게 정리하는 일을 좋아합니다.

## 프로젝트

### [PillBag · 약봉투 사진 → 쉬운 복약 설명](https://github.com/hangyeol2021/pillbag)

약봉투 사진에서 약 이름을 읽고, 식약처 허가정보의 어려운 설명(효능·용법·주의사항)을 환자가 읽기 쉬운 말로 바꿔 주는 서비스입니다.

- **데이터 구축:** 식약처 공공데이터 API로 의약품 허가정보(원문)와 e약은요(쉬운 설명)를 섹션 단위로 매칭해 학습쌍 구축
- **데이터 누수 발견:** 테스트 정답의 약 29%가 학습셋에 그대로 존재함을 확인하고 제거 후 재학습
- **모델:** KoBART 2종 파인튜닝(seed 3회 반복), Qwen2.5-7B 제로샷·규칙 기반 베이스라인과 비교
- **사실성 재순위화:** 용량·횟수 숫자와 금지 표현을 보존하는 후보를 선택해 숫자 보존율 76.5% → 80.5%, 금지 표현 누락 5.0% → 3.6%
- **기술:** Python · PyTorch · Hugging Face Transformers · EasyOCR · Gradio

### [Focus Sense · 공시](https://github.com/hangyeol2021/focus-sense)

웹캠의 자세 인식을 활용해 실제 공부시간을 측정하는 웹 서비스입니다. 기획부터 모델 학습, 클라우드 배포까지 혼자 진행했습니다.

- **자세 인식:** Google Teachable Machine · TensorFlow.js (브라우저 실시간 추론)
- **웹 개발:** JavaScript · HTML · CSS
- **인증·기록 저장:** AWS Cognito · API Gateway · Lambda · DynamoDB
- **배포:** EC2 · Nginx · CloudFront · S3

[소스 코드](https://github.com/hangyeol2021/focus-sense) · 실행 페이지는 운영 비용 문제로 현재 내려둔 상태입니다.
