## Featured project

### 공시 · Focus Sense

> 웹캠으로 공부 자세를 인식하고, 집중한 시간을 기록하는 웹 애플리케이션

**직접 구현한 내용**

- Google Teachable Machine의 자세 인식 모델을 웹 타이머와 연결
- 공부 자세에 따른 자동 측정과 수동 측정 기능 구현
- AWS Lambda, API Gateway, DynamoDB를 활용한 기록 저장·조회 기능 개발 및 클라우드 리소스 배포

**사용 기술**  
JavaScript · TensorFlow.js · Teachable Machine · AWS Lambda · API Gateway · DynamoDB
